# FinAppGO - Controle Financeiro Pessoal

Sistema de controle financeiro pessoal desenvolvido com React, Firebase e Vite.

## Funcionalidades

- ✅ Dashboard com indicadores financeiros
- ✅ CRUD de lançamentos (receitas/despesas)
- ✅ Gráficos interativos
- ✅ Autenticação com Firebase
- ✅ Banco de dados em tempo real
- ✅ Interface escura profissional

## Tecnologias

- React 18
- Firebase (Auth + Firestore)
- Vite
- Chart.js

## Como executar

```bash
npm install
npm run dev
